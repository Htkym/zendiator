# ZEN0035: Unsupported generation shape

Follow the reason in the diagnostic. A handler attribute only addresses a
missing handler marker.

## Missing handler marker

Add `[global::Zendiator.HandlerAttribute]` to the named handler class,
then rebuild.

The optional [Zendiator.CodeFixes](../../src/Zendiator.CodeFixes/README.md) package
offers **Add Handler attribute** for supported missing-marker cases.
Fix All applies to the current document only. If no fix is offered, edit the
named declaration manually.

## Other causes

On a composition marker, set `ClosedServiceCache` to
`ClosedServiceCacheMode.Inline` or `ClosedServiceCacheMode.LazyBlocks`. An undefined
enum value rejects the composition. Omitting the property selects inline storage.

An `EagerDependencies` entry must name a supported direct Send-route service.
Selecting a receiver on a synchronous-Before-only route preserves that route's
direct capture and uses its injected instance; it does not make unsupported
session, open generic or asynchronous hook shapes eligible. See the
[capture contract](../getting-started-0.5.0.md#route-local-capture-for-asynchronous-hooks).

Correct the registration, contract, generic arguments or accessibility named in
the diagnostic. Suppressing the diagnostic does not make the rejected route
supported.
