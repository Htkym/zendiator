# ZEN0025: Stage contract mismatch

The stage or factory lacks its required contract, its wrapper continuation is
incompatible, or an Owned session lacks the required cleanup contract. The full
message identifies the declaration to correct.

## Hooks and wrappers

For `Stage.Hook<T>()`, implement a dedicated hook interface for the selected
family. For `Stage.Wrapper<T>()`, choose the matching wrapper contract:

| Dispatch family | Wrapper contract | Continuation |
| --- | --- | --- |
| `SendSync` / `SendAllSync` | `ISendWrapper` | `ISendContinuation` |
| `SendAsync` / `SendAllAsync` | `IAsyncSendWrapper` | `IAsyncSendContinuation` |
| `Stream` | `IStreamMiddleware` | `IStreamUpstream` |

Match the continuation's type arguments to the wrapper contract.
For Stream, implement either the typed `OpenAsync<TNext>(request, TNext next, token)`
overload with `where TNext : struct, IStreamUpstream<TRequest,TItem>`, or the legacy
overload accepting `IStreamUpstream<TRequest,TItem>`. Both return
`ValueTask<IAsyncEnumerator<TItem>>`. The standard `IStreamMiddleware<TRequest,TItem>`
contract includes both overloads; `IStructStreamMiddleware` remains a compatibility name.
Invalid signatures or constraints report the required shape. Implementations that are not eligible
for a direct concrete call retain interface dispatch. Dispose every acquired upstream cursor; see
[Stream contracts](../streaming-0.5.0.ja.md) and
[typed Stream middleware](../migrating-stream-upstream.md).

## Session factories and cleanup

Implement one explicit session factory contract for the registered request and
session types: `IOwnedSessionFactory`, `IBorrowedSessionFactory`,
`IAsyncOwnedSessionFactory` or `IAsyncBorrowedSessionFactory`. Competing contracts
report ZEN0027; mismatched type arguments report ZEN0026.

| Route family | Factory completion | Owned session cleanup |
|---|---|---|
| `SendSync` / `SendAllSync` | Synchronous factory contract | Framework `IDisposable.Dispose()` returning `void` |
| `SendAsync` / `SendAllAsync` / `Stream` | Synchronous or asynchronous factory contract | Framework `IAsyncDisposable.DisposeAsync()` returning `ValueTask` |

Implement the cleanup interface on the session type, using the framework's exact
contract. A borrowed factory keeps cleanup with the external owner; select that
contract only when it matches the actual ownership. An asynchronous factory on
a synchronous route reports ZEN0030.

Zendiator provides no CodeFix for ZEN0025. Edit the named stage, factory, session
declaration or registration manually.
