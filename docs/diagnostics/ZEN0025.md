# ZEN0025: Stage contract mismatch

The stage has no dedicated contract for its declared role and dispatch family,
or its wrapper continuation is incompatible.

For `Stage.Hook<T>()`, implement a dedicated hook interface for the selected
family. For `Stage.Wrapper<T>()`, choose the matching wrapper contract:

| Dispatch family | Wrapper contract | Continuation |
| --- | --- | --- |
| `SendSync` / `SendAllSync` | `ISendWrapper` | `ISendContinuation` |
| `SendAsync` / `SendAllAsync` | `IAsyncSendWrapper` | `IAsyncSendContinuation` |
| `Stream` | `IStreamMiddleware` | `IStreamUpstream` |

Match the continuation's type arguments to the wrapper contract.
For Stream, OpenAsync accepts `IStreamUpstream<TRequest,TItem>` and returns
`ValueTask<IAsyncEnumerator<TItem>`> at an explicit opaque boundary. Dispose every
acquired upstream cursor; see [Stream contracts](../streaming-0.5.0.ja.md).

The experimental `IStructStreamMiddleware<TRequest,TItem>` capability additionally requires
`OpenAsync<TNext>(request, TNext next, token)` returning `ValueTask<IAsyncEnumerator<TItem>>`,
with `where TNext : struct, IStreamUpstream<TRequest,TItem>`. Invalid opted-in signatures or
constraints report the required shape. A valid implementation that is not eligible for a direct
concrete call retains the existing middleware boundary; see
[struct upstream support](../design/struct-stream-upstream.md).

Zendiator provides no CodeFix for ZEN0025. Edit the stage declaration or its
registration manually.
