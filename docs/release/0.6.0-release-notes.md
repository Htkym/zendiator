# Zendiator 0.6.0

0.6.0 changes the handler marker and standard Stream middleware contract.
Use .NET 10 and C# 14, keep Zendiator packages at matching versions, and rebuild consumers.

## Install

```shell
dotnet add package Zendiator --version 0.6.0
```

The optional `Zendiator.CodeFixes` package is installed separately at 0.6.0
with `PrivateAssets="all"`.

## Migrate

- Replace `[ZendiatorHandler]` with `[Handler]`. The public attribute is
  `Zendiator.HandlerAttribute`; the old attribute type is removed.
  Use `[global::Zendiator.HandlerAttribute]` if a local name is ambiguous.
- Standard `IStreamMiddleware<TRequest,TItem>` exposes `OpenAsync<TNext>`.
  Eligible sealed implementations use a struct upstream port automatically.
  Legacy interface adapters remain, but callers of replaced concrete sample
  methods must migrate. See [typed Stream migration](../migrating-stream-upstream.md).

DI service keys, lifetimes and disposal ownership are unchanged. `EagerDependencies`
remains explicit: inference does not safely determine whether a dependency will be
used or whether earlier construction is acceptable.

The existing pooled-producer feature remains an explicit opt-in with its
[documented restrictions](../design/pooled-producer-interceptors.md).

## Deployment and performance

Native AOT package consumers, including the standard typed Stream path, were
published and run on win-x64. Runtime open-generic DI closure with value-type
arguments remains limited; other RIDs are unverified. See [known limitations](known-limitations.md).

The README links the measured workload, source and raw numeric results.
The attribute rename changes source metadata recognition, not workload execution;
the existing measurements are retained without claiming a controlled release-to-release gain.
