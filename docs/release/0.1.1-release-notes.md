# Release notes — Zendiator 0.1.1

`0.1.1` is a maintenance release that reorganizes the source without changing public APIs
or generated consumer code. Upgrade `Zendiator.Abstractions` and `Zendiator` together;
no consumer code changes are required.

## Changes

- Organize library, sample, test and handwritten benchmark types into separate files.
  Same-name interface variants, necessary nested types and generated benchmark fixtures remain grouped.
- Split the Source Generator into semantic analysis, DI configuration, route discovery,
  request/notification/sync/stream processing and source emission files.
- Keep analysis state local to each generation run and add a regression test covering
  valid, invalid and corrected compilations processed by the same generator driver.
- Include every tracked C# file under `src` in the release source manifest.

## Verification

- 252 tests across 10 test projects, Release builds and the 24-project formatting gate.
- Before/after comparison: identical generated sources and diagnostics for 13 consumer compilations.
- Package consumers covering attribute-based and DI-first registration.
- The existing win-x64 Native AOT matrix, AOT01–AOT12, with the documented open-generic
  value-type DI closure limitation retained.

The release workflow rebuilds the tag commit, verifies package contents, consumers and Native AOT,
and publishes those exact packages through NuGet Trusted Publishing. It then checks restoration
from NuGet.org with a fresh package cache.

## Compatibility and limitations

Public contracts, generated dispatch behavior and DI lifetime semantics are unchanged.
The [known limitations](known-limitations.md) still apply. This release does not claim a performance
improvement or introduce new benchmark measurements; the [0.1.0 measurements](0.1.0-release-notes.md#performance)
remain the recorded baseline.

`0.1.1` is a `0.x` release. The API may change before `1.0.0`.

## Installation

```xml
<ItemGroup>

  <PackageReference Include="Zendiator" Version="0.1.1" />
```
