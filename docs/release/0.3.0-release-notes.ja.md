# Zendiator 0.3.0 リリースノート

[English](0.3.0-release-notes.md)

0.3.0 では、生成される依存サービスの登録と Mediator の破棄時の契約が変わります。通常の `AddZendiator()`、Mediator の既定 Scoped、共通の `IZendiator.SendAsync` は維持します。0.2.0 から更新する場合は、以下を確認してください。

## 依存サービスの有効期間

既定の Scoped Mediator を使う場合、生成される Handler と Behavior の登録は Transient になります。0.2.0 では Mediator と同じ Scoped でした。Zendiator は引き続き、サービス型ごとに最初に取得したインスタンスを Mediator 単位で保持します。Transient でも、同じ Mediator から送信するたびに取得し直すわけではありません。今回変わるのは、同じスコープ内の別の利用者との共有や、別の Mediator インスタンスを生成したときの動作です。

以前と同じ Scoped の共有が必要な場合は、`configuration.DependencyLifetime = ServiceLifetime.Scoped` を指定するか、対象サービスを `AddZendiator()` より前に Scoped で登録してください。更新時には、生成回数、呼び出し間の状態、並行利用、破棄の担当を確認してください。構成用のオーバーロードでは Mediator と依存サービスの有効期間を別々に指定できます。生成と破棄は DI が担当します。

## Mediator の破棄と移行

生成される Mediator は `IDisposable` を実装しなくなりました。送信とストリーム列挙が終わってから DI スコープを破棄してください。スコープやルート Provider の破棄後に、保持済みの Mediator から送信する使い方はサポートしません。従来の `ObjectDisposedException` が必ず発生する保証もなくなります。`ZendiatorRootLifetime` と、それを受け取るコンストラクターのオーバーロードを削除しました。`ZendiatorServiceResolver.Dispose()` を直接呼ぶコードも変更が必要です。

生成器パッケージには、確実に判定できる寿命の誤用を知らせる ZEN0021～ZEN0023 の警告を同梱します。対象は、生成 Mediator の明示的な `IDisposable` 扱い、`using` スコープからの返却、同じメソッド内でスコープを明示的に破棄した後の送信です。複雑な非同期処理やフィールドに保持した Mediator の安全性までは判定しません。送信が終わるまでスコープを維持してください。詳しくは[移行ガイド](../migrating-from-mediatr.ja.md)と[有効期間の説明](../optimized-dispatch.md)を参照してください。

一部の生成 Mediator は、構成ごとの Resolver または単一依存用 Resolver を基底型に使います。通常の `AddZendiator()` と `IZendiator.SendAsync` の呼び方は変わりません。生成クラスの正確な基底型を調べるコードは修正し、生成器と実行時パッケージの版をそろえて利用側を再ビルドしてください。

## 性能と制限

構成ごとのサービス番号により、無関係な Mediator 構成が多数の型を先に使った場合の疎なキャッシュページ確保を避けます。適用できる経路では単一依存用 Resolver を使います。これらの変更だけで全用途の速度順位を主張するものではありません。同期完了する無割り当ての Handler と Behavior を使うウォーム経路では、送信あたり追加確保量 0 B の条件を維持します。初回 DI 解決と非同期中断には別の費用があります。[ユースケース別ベンチマーク](../../benchmarks/README.ja.md)で Send、Notification、Stream の比較を再現できますが、各ケース1回の実行結果でライブラリ全体の最速は確定できません。

値型で閉じたオープンジェネリック DI Handler の Native AOT 制限などは[既知の制限](known-limitations.md)を参照してください。Native AOT の検証対象は win-x64 です。

## インストールと更新

```shell
dotnet add package Zendiator --version 0.3.0
```

`Zendiator` は Generator を含み、`Zendiator.Abstractions` に依存します。両方を明示的に参照している場合は 0.3.0 にそろえ、利用側を再ビルドして配送コードを再生成してください。既定の登録方法は変わりません。

```csharp
using Zendiator.DependencyInjection;

services.AddZendiator();
```

利用例と対応する操作は [README](../../README.ja.md) を参照してください。
