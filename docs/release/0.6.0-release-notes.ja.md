# Zendiator 0.6.0

0.6.0ではHandler属性と標準Stream middlewareの契約を変更しました。
.NET 10とC# 14を使い、Zendiatorのパッケージを同じバージョンに揃えて利用側を再ビルドしてください。

## インストール

```shell
dotnet add package Zendiator --version 0.6.0
```

任意の `Zendiator.CodeFixes` は0.6.0を `PrivateAssets="all"` 付きで別途導入します。

## 移行

- `[ZendiatorHandler]` を `[Handler]` に変更してください。公開属性は
  `Zendiator.HandlerAttribute` で、旧属性型は削除しました。
  ローカルの名前と曖昧になる場合は `[global::Zendiator.HandlerAttribute]` と書けます。
- 標準の `IStreamMiddleware<TRequest,TItem>` は `OpenAsync<TNext>` を公開します。
  条件を満たすsealed実装では、structの上流portを自動で使います。
  旧interfaceとのadapterは残りますが、置き換わったsampleの具体型メソッドを直接呼ぶコードは移行が必要です。
  [型付きStreamの移行](../migrating-stream-upstream.md)を確認してください。

DIのservice key、ライフタイム、破棄の担当は変えていません。`EagerDependencies` は引き続き明示指定です。
依存が使われるか、生成時期を早めてよいかを、使用状況の推測だけで安全には決められません。

既存のpooled producerは、[対応する範囲](../design/pooled-producer-interceptors.md)で明示的に有効にする機能です。

## 配置と性能

標準の型付きStream経路を含むpackage利用アプリケーションは、win-x64のNative AOTでpublish・実行を確認しています。
値型の型引数を使うopen-generic DIの実行時閉包には制約が残ります。ほかのRIDは未確認です。
[既知の制約](known-limitations.md)も確認してください。

READMEから測定対象の処理・ソース・丸め前の数値を参照できます。
属性名の変更は、ソースのメタデータを認識する名前の変更で、測定対象の処理は変えていません。
既存の測定を保持しますが、リリース前後の改善を示す比較とはしていません。
