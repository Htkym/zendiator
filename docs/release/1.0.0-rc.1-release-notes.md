# Zendiator 1.0.0-rc.1

The release candidate targets .NET 10 and C# 14. Use the same version of `Zendiator` and `Zendiator.Abstractions` in your application, restore packages and rebuild. The [upgrade guide](../upgrading.md) covers package references, startup code, and earlier 0.x changes. [日本語の更新ガイド](../upgrading.ja.md)

## DI registration

`services?.AddZendiator<App>(...)` now registers a non-null service collection and skips a null receiver. The receiver is evaluated once. Calling the extension method directly or using its fully qualified static name also works. Converting the registration method itself to a delegate now produces [ZEN0020](../diagnostics/configuration.md#zen0020) at build time. A host that expects a callback can take a lambda or helper method containing the direct call.

## Stream middleware

Middleware can return an upstream cursor directly, return through a local variable, or wrap the cursor in a decorator. Zendiator uses the returned cursor and effective cancellation token to decide how to enumerate it. A decorator keeps its item and disposal behavior. Existing consumers keep calling `StreamAsync` and using `await foreach`. [Stream guide](../streaming.md)

## Compatibility

The mediator retains the 0.7.0 DI lifetime rules, including reuse of Transient receivers. From 1.0.0 onward, incompatible changes to documented public APIs or their documented behavior require a new major version. The optional `[GeneratePooledProducer]` feature remains experimental. Its accepted method bodies and diagnostics may change within 1.x. [Compatibility and supported configurations](known-limitations.md)
