## 候補測定前に固定した判定方針

14:37:55 UTC に [decision policy](experiments/decision-policy-2026-11-07.json) を保存した。この時点で候補の時間測定は開始していない。実用上の時間差の判定幅は 3%、割り当て差の許容幅は 0 B とし、独立した 3 組を baseline→candidate / candidate→baseline / baseline→candidate の順で比較する。

時間改善は 3 組すべてが改善方向で、比率中央値が 0.97 未満の場合だけ報告する。割り当てだけが改善しても、時間が 3 組すべて悪化方向なら、3% 以内であっても時間の保護は未証明として候補を採用しない。各 round の値と比率を残し、候補結果を見て判定幅を広げない。

sync early break 5 段の baseline CV は 3.30%、async Relay5 は 4.44% だった。async early break 0/5 段と初回 Send0/5 は CV が 5% を超えたため、不確実性の高い保護ケースとして表示する。この不確実性を理由に 3% 幅を広げたり、当該ケースを除いたりしない。未確定の保護ケースがあるときは、無条件の「回帰なし」とは報告しない。
